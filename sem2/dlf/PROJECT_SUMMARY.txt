MODEL ARCHITECTURE
--------------------------------------------------------------------------------
Image Path:
  RGB Image (224×224) 
    → ResNet-50 (pretrained)
    → CNN Features (2048-d)
    → Projection (512-d)
    → Final Projection (256-d)

Text Path:
  Text (words)
    → Word Embeddings (256-d, vocab ~10K)
    → Bidirectional LSTM (2 layers, 256 hidden)
    → Concatenate directions (512-d)
    → Projection (256-d)

Fusion:
  Image Emb (256-d) + Text Emb (256-d)
    → [Concatenation | Element-wise Multiply]
    → Combined Features (768-d)
    → MLP (768 → 256 → 128 → 1)
    → Sigmoid → Output [0, 1]

Parameters: 27,935,297 (27.9M)
Model Size: ~107 MB

--------------------------------------------------------------------------------
HARD NEGATIVES STRATEGY
--------------------------------------------------------------------------------
The key to good performance on adversarial test sets:

Hard Negatives (70% of negatives):
  1. Color substitution: "red car" → "blue car"
  2. Number substitution: "three dogs" → "two dogs"
  3. Object substitution: similar but different objects
  4. Attribute manipulation: subtle semantic changes

Easy Negatives (30% of negatives):
  - Random mismatched image-caption pairs

Purpose: Force model to use both modalities and understand semantic details

COMMON ISSUES & SOLUTIONS
--------------------------------------------------------------------------------
Issue: Low accuracy (~50%)
  → Increase hard negatives ratio
  → Train longer (50+ epochs)
  → Verify data quality

Issue: Overfitting
  → Increase dropout (0.3 → 0.5)
  → Add more training data
  → Use data augmentation

Issue: Out of memory
  → Reduce batch size (32 → 16)
  → Use smaller model (ResNet-34)

Issue: Model not learning
  → Check data loading
  → Verify loss calculation
  → Lower learning rate
